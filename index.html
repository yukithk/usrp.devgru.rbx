// MISSION OBJECTIVE / 核心使命

DEVGRU 是一支隸屬於美軍聯合特種作戰司令部（JSOC）的頂尖 Tier 1 特種部隊。在 Roblox MilSim 的戰場中，我們專注於高難度反恐、人質營救、敵後偵察與斬首行動。我們不追求人數，我們只追求極致的戰術素養、鋼鐵般的紀律與完美的團隊默契。

「在戰場上，平庸即是死罪。我們只要最頂尖的 1%，其餘免談。」

// ORDER OF BATTLE / 中隊編制

Gold Squadron

金衣中隊。突擊主力，負責正面攻堅、反恐（CT）作戰與高難度人質營救任務。

Blue Squadron

藍衣中隊。擅長海上攔截（VBSS）、登船奪控以及各類熱點區域的快速突擊部署。

Black Squadron

黑衣中隊。情報與監視。負責戰區前哨滲透、遠程狙擊觀測與機密情報蒐集（需獨立選拔）。

Gray Squadron

灰衣中隊。戰術載具與航空支援。負責全隊的滲透、空中/水面火力壓制與安全撤離。

// ENLISTMENT RULES / 入伍守則

  • 通訊設備： 必須擁有清晰、無雜音的麥克風，且在行動中必須服從語音調度。
  • 絕對服從： 官方演習與作戰行動中，對長官（High Ranks）的戰術指揮擁有 100% 的執行力。
  • 選拔淘汰制： 所有新兵入伍一律為 Candidate，必須通過 BUD/S 基礎訓練與 OTC 進階選拔，未通過者一律淘汰。
